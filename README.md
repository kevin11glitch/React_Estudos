## 🧠 Conceitos e Tecnologias

Ao longo de 70 horas de conteúdo, os estudos neste repositório englobam:

### Core e Fundamentos
- **Arquitetura Base:** Componentes, Props, JSX e fluxo unidirecional de dados.
- **Estado e Reatividade:** `useState`, renderização condicional e manipulação de eventos.
- **Hooks (Profundo):** `useEffect`, `useReducer`, `useContext` e criação de Custom Hooks.

### Gerenciamento de Dados e Rotas
- **Estado Global:** Context API, Redux e Redux Toolkit.
- **Comunicação:** Integração com APIs Restful, requisições HTTP e tratamento de respostas/erros.
- **Roteamento:** React Router para SPAs dinâmicas.

### Ecossistema Avançado
- **Next.js (14+):** Desenvolvimento fullstack, SSR (Server-Side Rendering) e React Server Components.
- **Qualidade de Código:** Integração profunda com TypeScript e Testes Unitários.
- **Estilização e UI:** CSS Modules, Styled Components, Portals, Fragments e Animações.
- **Formulários:** Validação robusta e novas React Form Actions.
